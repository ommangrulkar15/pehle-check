# Pehle Check

A mobile-first website that helps first-time buyers in India check a used phone before paying. Concept project by Om Mangrulkar (UI/UX).

**All prices and findings are sample data.** No live price source or official verification is connected. The research behind it is assumptions, still to be tested with real buyers.

- Case study: https://www.behance.net/gallery/258181493/Pehle-Check-check-a-used-phone-before-you-pay
- Built with plain HTML, CSS and JavaScript. No build step: open `index.html` or run `python -m http.server`.
- See `DATA-NEEDS.md` for the real data this would need to go live.
